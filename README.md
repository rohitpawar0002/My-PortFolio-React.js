## Run locally

```bash
git clone https://github.com/rohitpawar0002/My-PortFolio-React.js.git
cd My-PortFolio-React.js
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

### Useful scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Local development server |
| `npm run build` | Production build → `dist/` |
| `npm run preview` | Preview the production build |
| `npm run lint` | ESLint |

### Chatbot (optional)

The AI chat uses a Netlify function. For local chat, set your Gemini API key in the Netlify / env setup used by `netlify/functions/chat.js`. The rest of the site works without it.
